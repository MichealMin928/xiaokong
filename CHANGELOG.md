# Changelog

## 0.6.1-rc2 — Community preview

First public source release of XiaoKong. This imports the existing Android voice/gesture project; it does not represent a newly collected community accuracy benchmark.

- Publish source under Apache-2.0, keeping third-party model terms separate.
- Add Chinese/English onboarding, contribution, privacy, testing and architecture guides.
- Pin model/AAR downloads and checksums; exclude private recordings, internal evidence and binary history.
- Separate private human-recording regression tests from public tests.
- Add GitHub participation links in the app without automatic feedback upload.
- Prepare a dedicated signed ARM64 preview with source-linked release notes.

Recognition quality, media playback interference, cross-brand behavior, and sustained power use still need real-user validation. See [roadmap](docs/public/ROADMAP.md).
