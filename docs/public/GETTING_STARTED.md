# 开始使用小空

## 安装与升级

从 [Releases](https://github.com/MichealMin928/xiaokong/releases) 下载社区预览 APK。首发包为 ARM64，最低 Android 8；其他架构可以从源码构建。安装前可用发行页的 `SHA256SUMS` 校验文件。

社区包使用专门的发布签名。此前内部 debug 包或自行编译的包可能提示签名不一致，不能覆盖安装。已有用户先导出重要反馈和训练记录；不要为了升级直接卸载并丢失数据。当前没有训练记录导入迁移工具，导出用于保留资料，不能保证在新安装中恢复。新用户直接安装即可。

## 首次启动

1. 阅读权限说明。语音需要麦克风；手势需要前摄；跨应用控制需要无障碍服务和悬浮窗。
2. 按引导打开对应系统设置。Android 13+ 的旁加载安装可能需要在“应用信息 → 右上角菜单”允许受限设置，位置因厂商而异。仅对你信任的安装包操作。
3. 回首页选择语音、手势开关。只想语音操作时关闭手势，相机可以不运行。
4. 先在安静环境使用“安静直接”模式，无需唤醒词。说完一句稍停，再说下一句。
5. 任意时候可通过首页或通知结束控制。锁屏应停止采集；异常用反馈模板记录。

## 语音

下表来自 App 的固定指令词表。并非自由对话助手，不支持任意口述指令。

| 目的 | 可以说 |
| --- | --- |
| 上下翻页 | 上滑、向上滑动；下滑、向下滑动 |
| 左右换页 | 左滑、向左滑动；右滑、向右滑动 |
| 返回 | 返回、返回上一页 |
| 回到桌面 | 回到桌面、返回桌面、桌面、主页 |
| 最近任务 | 最近任务 |
| 显示可点按钮 | 显示按钮、显示编号、编号、按钮 |
| 显示有按钮的区域 | 分区选择、屏幕分区、网格 |
| 点编号 | 一号、点击五号、选择十二号；范围 1–20 |
| 开启手势及鼠标 | 开启手势、打开手势、鼠标 |
| 关闭手势 | 关闭手势、关闭鼠标 |
| 取消编号 | 取消、取消选择 |
| 暂停和恢复 | 暂停控制；恢复控制 |

编号出现后再说数字。页面滚动或切换后旧编号会失效，请重新显示。没有可读控件的页面可能显示不了按钮；分区也只包含发现控件的区域。

唤醒模式中，普通滑动等操作需先说设置中选定的唤醒词，5 秒内发出指令；下一次普通操作需重新唤醒。显示按钮、分区选择、取消、关闭手势、暂停和恢复可直接说。短词漏听、口音和视频外放仍可能影响效果，暂不建议把外放环境当作已验证场景。可在“语音识别设置”做跟读测试，并查看“近期语音记录”的时间、识别和动作结果。旧识别文字不表示新一句已听到。

## 手势

开始前让整只手处于摄像头内，保持良好光照。左右手均可；“向左/向右”指你希望页面执行的滑动方向，首次请用本机模拟界面熟悉镜像映射。

| 操作 | 手形和运动 |
| --- | --- |
| 上滑 | 除拇指外四指朝上，整只手向上移 |
| 下滑 | 食指、中指仍朝上，整只手向下移；不是指尖朝下 |
| 左滑 | 五指张开、朝上，整只手向左移 |
| 右滑 | 食指、中指朝上，整只手向右移 |
| 鼠标 | 其余手指握起，单独伸食指瞄准；没有鼠标手形时小圆点隐藏 |
| 点击 | 瞄准后，拇指向食指靠近、离开、再靠近；不必指尖接触 |
| 返回 | 指尖侧向的手掌横推 |
| 桌面 | 拇指和小指伸出，比“6”，稳定保持 |
| 点赞 / 不喜欢 | 单独伸拇指后连续上移两次 / 下移两次；实际效果取决于目标 App |

鼠标拖动、眼控阅读和应用模式在工具/设置中提供，属于需要单独验证的功能。请先完成基本点击再测试拖动，不要用重要操作作为首次试验。

## 遇到问题

- **听到了但没执行**：记录“近期语音记录”的时间和处理结果；确认无障碍仍开启、控制没有暂停、页面支持该方向。
- **叫不醒或编号漏听**：先换到安静直接模式测试；报告模式、词语、环境、次数和成功数。
- **光标卡顿**：检查完整手形是否出框、光线和温度；在同一角度重复固定路线，记录断点。
- **视频误触或漏听**：暂停视频后对比；回声消除状态不代表已经消除了外放干扰。

从 App“帮助与问题反馈 → 社区反馈”打开模板，或直接访问 [Issues](https://github.com/MichealMin928/xiaokong/issues/new/choose)。打开链接不会自动提交本机数据。
