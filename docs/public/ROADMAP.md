# 路线图与已知问题

这是工作方向，不是已完成清单或承诺日期。讨论和进度以 GitHub Issues 为准。

| 优先级 | 需要解决或验证的问题 | 验收方式 |
| --- | --- | --- |
| 高 | 短口令、唤醒词、显示按钮漏听 | 安静/外放对照，分别记录漏听、误触和延迟 |
| 高 | 重复口令长会话失效 | 连续指令、暂停恢复、切后台与麦克风交接复现 |
| 高 | 鼠标卡顿和拇指点击漏识别 | 左右手、多个角度，光标连续性与目标偏移 |
| 高 | 手势收手误触和方向互斥 | 上下左右往返负例，零指令时额外动作计数 |
| 高 | 跨品牌生命周期与功耗 | 厂商、Android 版本、锁屏/解锁及 30–60 分钟结果 |
| 中 | 可访问性和第一次使用 | TalkBack、放大字体、权限说明和低学习成本 |
| 中 | 中英文文档与反馈质量 | 完整安装流程及可复现问题模板 |
| 后续 | 眼控阅读与拖动 | 独立校准和误触评估，不混入核心通过率 |

当前限制：仅有限中文口令；编号依赖可读取控件；相机遮挡和低光影响跟踪；发布包体较大；Android 8 是最低版本声明，不等于所有 Android 8 设备已验证。无登录、云端语音或遥测。

首轮欢迎贡献设备测试、上手说明、无障碍可读性检查和最小复现用例。先讨论大规模替换识别引擎、模型许可变化及新增敏感权限。
